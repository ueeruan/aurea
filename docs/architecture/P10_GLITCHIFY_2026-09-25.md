# Glitchify expansion

## Original implementation
Official product direction: https://elementsupply.co/products/glitchify — Cinema Spice describes pixel sort, channel scaling, RGB splitting and block/transform glitches. No vendor source, assets or implementation was copied.

Existing indices 0–9 are retained. New animated controls append 10 Pixelization, 11 RGB scale, 12 Block width, 13 Block displacement, 14 Horizontal tears, 15 Flicker, 16 Pixel sorting. All new destructive controls default to zero. Generic effect metadata exposes the same controls on Android and iOS without separate platform shaders.

Pixel sorting stably ranks luminance within 16-pixel row segments selected by seeded hash. It preserves premultiplied samples and is skipped when disabled. This is bounded local sorting, not an unlimited full-row sorter. Other modules use layer-space coordinates and deterministic integer hashes of source grid, seed and quantized local frame.

Corrected existing bugs: Freeze did not affect shader time; RGB split applied normalized offsets through a second normalization; band/displacement coordinates depended on expanded output padding rather than input layer bounds. Mixture remains premultiplied and zero mixture bypasses the effect.

## Validation pending consolidated build
- `Gpu.GlitchifyModulesFreezeAndFinalQualityAreDeterministic`: each added module and RGB split change actual GPU pixels; finite output; reverse seek, freeze, zero mix, and finalQuality equivalence.
- `Gpu.GlitchifyNewControlsAnimateAndSurviveSaveLoad`: native key commands, midpoint/end renders, random seeks and project save/reopen.
- `git diff --check` passed.

These tests use actual host GPU rendering but do not establish iOS Metal runtime or encoded Android/iOS export validation. Sorting is optional and has a greater sampling cost; no unsupported device-performance claim is made.
