# P10 — Film halation effect (2026-09-25)

## Visual direction

CapCut's own 2026 transition guide highlights speed ramps, RGB/glitch and
slow-motion/blur combinations; Alight Motion documents thresholded light glow
and optional halos. These are product references for useful editing tools,
not evidence that this new halation effect itself is currently viral. The
implementation below is original and uses Aurea's existing Gaussian builder;
no external shader/code was copied. [CapCut guide](https://www.capcut.com/help/capcut-transitions), [Alight Light Glow guide](https://guide.alightmotion.com/effects/light-glow)

## Implemented behavior

`aurea.light.halation` is a new Neighborhood effect in the shared registry.
It extracts premultiplied linear luminance above a soft threshold, diffuses
that energy with the existing bounded Gaussian pyramid, subtracts a controlled
amount of the undiffused local energy, and adds a warm tint. At the default
100% nucleus preservation, uniform bright interiors remain neutral and the
warm light appears mainly on their dark-side boundaries. This differs from
Deep Glow's two broad additive/screened halos.

Controls: highlight threshold, radius in layer pixels, amount, threshold
softness, nucleus preservation, halo color and halo-only display. Float/color
controls use the normal animatable parameter contract. All uniforms and
parameter state follow the existing frame snapshot/serialization/effect path.
Both Android and iOS consume the shared catalog/parameters; GLSL is compiled
through existing Vulkan/GLES/Metal shader pipelines.

The effect uses region-to-input UV maps for every source and transparent border
sampling. Added light can extend into transparency with bounded added coverage,
without making an expanded rectangular margin opaque. Amount zero is an
identity when halo-only is off. The extraction clamps selected energy to actual
input luminance so a zero threshold/soft knee never creates light from black.
