# Aurea Beta 0.5.2 — notas para a Play Console

## pt-BR
<pt-BR>
• Nova tela de Armazenamento: veja o que ocupa espaço e limpe o que não é usado
• Apagar um projeto libera a mídia que só ele usava
• Importar de novo o mesmo PSD, GIF ou sequência não duplica mais
• PreRender limitado a 4 GB e sem pastas perdidas
• Exportação não trava mais em "Preparando" e o Cancelar funciona
• Exportação não recomeça do zero várias vezes
• Exportação mais rápida e mais leve em aparelhos com pouca memória
• Corrigido o "+" depois de trocar de Edição para Composição
</pt-BR>

## en-US
<en-US>
• New Storage screen: see what takes up space and clear what isn't used
• Deleting a project frees the media only it used
• Importing the same PSD, GIF or sequence again no longer duplicates it
• PreRender capped at 4 GB, with no stray folders
• Export no longer gets stuck on "Preparing", and Cancel works
• Export no longer restarts from scratch several times
• Faster export, lighter on low-memory devices
• Fixed "+" after switching from Edit to Composition
