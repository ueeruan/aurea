# Aurea Beta 0.5.3 — notas para a Play Console

## pt-BR
<pt-BR>
• Exportação mais confiável: retoma se o app fechar, não cancela no fim e nunca apaga o vídeo pronto
• Mais codificadores tentados, com limite de memória por aparelho
• Prévia sem engasgos e app abrindo mais rápido
• Controles mais leves durante o toque
• Animador de texto: alinhamento de caractere, mesclagem entre letras e seletor Varredura
• Expressão no texto: máquina de escrever, contador e bounce
• Correções: fotos que fechavam o app, tela pulando, TimeSlice em 1080p; grupos abertos
</pt-BR>

## en-US
<en-US>
• More reliable export: resumes if the app closes, no longer cancels at the end and never deletes the finished video
• More encoders tried before giving up, with a memory limit per device
• Smoother playback preview and faster app start
• Lighter panels and sliders while you drag
• Text animator: character alignment, inter-character blending and Sweep selector
• Text expressions, with typewriter, counter and bounce presets
• Fixes: two-photo crash, layout jump, 1080p TimeSlice; expandable groups
</en-US>
